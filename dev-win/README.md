# Dev scripts (for Windows)

The files were converted from the original Bash scripts to run on Windows using PowerShell.

My experience with both Bash and PowerShell is limited, so only selected scripts were converted.

You only need to have [7-zip](https://www.7-zip.org) and [VPKEdit](https://github.com/craftablescience/VPKEdit) installed and in your PATH for the scripts to work.
